# Exercise Labels Feature

## Overview
You can now organize your exercises using labels to categorize them by workout routine.

## Available Labels
- **Workout A** - Exercises for your A workout day (e.g., Squat, Bench Press, Rows)
- **Workout B** - Exercises for your B workout day (e.g., Squat, Overhead Press, Deadlifts)
- **Additional** - Supplementary exercises (e.g., curls, accessory work)

## How to Use

### Adding a New Exercise with a Label
1. On the main page, enter the exercise name
2. Select the appropriate label from the dropdown (defaults to "Additional")
3. Click "Add Exercise"

### Filtering Exercises
At the top of the main page, you'll see filter pills:
- **All** - Show all exercises
- **Workout A** - Show only Workout A exercises
- **Workout B** - Show only Workout B exercises  
- **Additional** - Show only additional exercises

Click any filter to view only exercises with that label.

### Visual Indicators
- Each exercise card displays a colored badge with its label:
  - **Blue** badge = Workout A
  - **Red** badge = Workout B
  - **Gray** badge = Additional

### Mobile Experience
On mobile devices, you'll see:
- Horizontally scrollable filter pills at the top
- Color-coded label badges next to exercise names
- Full-width forms for easy input

## Migration
Existing exercises have been automatically labeled as "Additional". You can create new exercises with different labels as needed.

## Tips
- Use Workout A and Workout B for your main Greyskull LP lifts
- Use Additional for accessory exercises, plugins, or deload variations
- Filter by label to quickly see what exercises are due for each workout day
